# Regex to NFA Visualizer

This is a visual tool built with **Next.js**, **TypeScript**, and **TailwindCSS** to convert and visualize regular expressions to nondeterministic finite automata (NFA).

## Getting Started

```bash
npm install
npm run dev
Visit http://localhost:3000 to use the tool.

## Features

- ✅ Input regex expression
- 🔍 Step-by-step NFA visualization
- 🎨 Clean UI built with TailwindCSS

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [TypeScript](https://www.typescriptlang.org)
- [TailwindCSS](https://tailwindcss.com)
